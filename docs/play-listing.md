## 商店描述模板（可复制）

DSH Remote 是 DeepSeek Harness 的非官方手机遥控客户端：连接你电脑上正在运行的
DeepSeek Harness 服务，随时随地给智能体派任务、看进展、批审批。

功能亮点：
- 局域网直连或 cpolar 内网穿透，任何网络可用
- 扫码自动连接（扫描电脑端远程控制二维码）
- 审批 / 问答确认 / 任务完成实时通知，点击直达会话
- 实时流式对话：Markdown 渲染、工具调用卡片、图片消息、语音转文字（微信通道）
- 可拓展主题：内置深蓝 / 纯黑 / 暖白三套主题，支持导入自定义 JSON 主题
- 背景图自定义：模糊 / 饱和度 / 蒙层 / 面板通透度，一键预设
- 自适应模型：短问答自动走 Flash，复杂任务自动切 Pro
- 无账号、无广告、无遥测，数据只存在你的手机和你自己的服务器

注意：本应用为第三方非官方客户端，与 DeepSeek 官方无关。使用时需要自备
DeepSeek Harness 服务端（https://github.com/deepseek-ai/deepseek-harness）。

## 政策风险提示

- 本应用连接用户自建服务器，属于通用工具类，政策风险低
- 应用名/描述避免使用 DeepSeek 商标暗示官方授权（当前已加"非官方"声明）

- 若用户反馈连接非本人服务器导致泄露，责任在用户侧配置，隐私政策已写明
