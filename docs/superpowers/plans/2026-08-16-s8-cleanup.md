- [ ] **Step 1: 写失败测试** `CiphertextShapeTest.kt`：合法 Base64 长度>=28 → true；合法 Base64 短于 28 → false；非法 Base64（含非 base64 字符/长度不对齐）→ false；空串/空白 → false；明文文本 → false。
- [ ] **Step 2: 实现 `isCiphertextShape`**（`java.util.Base64` 解码 + 长度判定，runCatching 容错——与 `decryptProfileFromStorage` :361-364 同款）。
- [ ] **Step 3: `encryptProfileForStorage` 接线**：`pw` 非空时先判 `isCiphertextShape(pw)`——已具密文形态则**原样返回**（不二次加密）；否则 `box.encrypt(pw)`。即：
```kotlin
internal fun encryptProfileForStorage(p: HostProfile, box: SecretBox): HostProfile {
    val pw = p.proxy?.password
    if (pw.isNullOrBlank()) return p
    if (isCiphertextShape(pw)) return p   // 密钥丢失残存密文：不再二次加密
    return p.copy(proxy = p.proxy.copy(password = box.encrypt(pw)))
}
```
- [ ] **Step 4: 回归测试补充** `SettingsStoreSecretTest.kt`：新增用例——`encryptProfileForStorage` 对已是密文形态（FakeBox 产出的 `ENC:...` 不算，需真实形状如 Base64≥28）的密码不再二次加密（用假 box 返回 `"QUFB..."` 形状密文验证原样保留）。同步确认既有用例（明文→加密、空→原样）仍绿。
