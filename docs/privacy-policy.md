# DSH Remote 隐私政策

更新日期：2026-08-15

DSH Remote（下称"本应用"）是一个**非官方**的第三方客户端，用于远程操控用户自建/自有的 DeepSeek Harness 服务。本应用**不收集、不存储、不上传**任何个人数据。

## 我们收集什么

**我们不收集任何数据。** 本应用没有账号体系、没有遥测、没有广告 SDK、没有分析 SDK、没有推送云服务。

## 数据存储位置

- 服务器地址、主题、外观设置等全部数据仅保存在**你的手机本地**（应用私有存储 / DataStore）。
- 自定义主题文件保存在应用私有目录（filesDir/themes），不会上传。
- 连接凭据（如有）仅存在于你的手机与你自建的 DSH 服务器之间。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 网络访问 | 连接你自己配置的 DSH 服务器地址 |
| 通知 / 前台服务 | 后台常驻连接，审批、确认、任务完成时提醒你 |
| 相机 | 扫描 DSH 远程控制二维码，自动填入服务器地址 |
| 读取存储（文件选择器） | 选择背景图片、导入自定义主题 JSON |

## 第三方

- 本应用不包含任何第三方 SDK（zxing 扫码库在本地运行，不联网）。
- 你连接的服务器由你自己控制；你发送的消息内容由你自己的 DSH 实例处理。
