# 节点小宝 + DSH 手机远控 使用教程

> 目标：在**没有公网 IP** 的情况下，用**节点小宝**（国产内网穿透/异地组网工具）把你的电脑 DSH（端口 **8787**）映射成一个公网可访问的地址，让手机上的 DSH Remote App 在任何网络都能连上来。
> 本教程与 DSH v1.8.0 / 插件 **v2.4.0** 配套：**PC 端会自动生成 6 位配对码**，手机输入即可配对；手机经公网域名连接时需把该域名加进**公网域名信任白名单**，否则核心 Host 围栏会 403。

---

## 一、原理（30 秒看懂）

- DSH（DeepSeek Harness）在你的电脑上跑一个本地 Web 服务，默认端口 **8787**。
- 局域网里手机填 `http://电脑IP:8787` 就能连；但出了家门（公网），电脑没有公网 IP，连不上。
- **节点小宝**负责「内网穿透」：把你电脑的 `8787` 映射成一个**公网域名:端口**（形如 `xxxx.nodebao.xxx:xxxxx`），手机在任意网络填这个公网地址就能连回你家电脑。
- DSH 带安全保护（这是好事）：
  - 手机连接时 Host 是公网域名，DSH 核心默认只认局域网/本机，会 403 —— 需要把公网域名**加进白名单**。
  - 首次连接要**配对**（PC 端自动生成 6 位码，手机输入即完成），配对后才下发远程令牌，陌生人也连不进。

---

## 二、你需要的东西

| 项 | 说明 |
|---|---|
| 电脑 | 已装并运行 DSH（DeepSeek Harness），本地端口 **8787** 可访问 |
| 节点小宝 | PC 端 Windows 客户端（用来做内网穿透映射） |
| 节点小宝手机 App | 手机上装（也可用作异地组网/管理），同一账号 |
| DSH Remote App | 手机上的远控 App（本仓库产物） |

---

## 三、操作步骤

### 第 1 步：装并登录节点小宝
1. 在**电脑**下载安装节点小宝 Windows 客户端，注册/登录/扫码登录；
2. 在**手机**装节点小宝 App，登录**同一个账号**（用于异地组网时互相可见，也可仅作管理）。

> 菜单名称可能随版本略有差异，但核心流程一致：**做一条「内网穿透/公网访问」映射，把本地 `8787` 指到公网**。

### 第 2 步：把 DSH 的 8787 端口映射到公网
1. 打开节点小宝 PC 端，找到**内网穿透 / 公网访问 / 隧道 / 端口映射**入口（不同版本叫法不同）；
2. 新建一条映射，填：
   - **本地地址**：`127.0.0.1`（或你电脑的局域网 IP）
   - **本地端口**：`8787`
   - **协议**：`HTTP`（如有 HTTPS 选项，最好用 HTTPS；没有先用 HTTP 也能跑）
3. 启动/保存后，节点小宝会给你一个**公网访问地址**，形如：
   ```
   http://xxxx.nodebao.xxxx:端口   或   https://xxxx.nodebao.xxxx
   ```
   **记下它**（只取 `主机名`，不带 `http(s)://` 前缀）。

### 第 3 步（必须）：把公网域名加进 DSH 白名单
手机连的是公网域名，DSH 核心默认会 403。加白名单（插件 v2.4.0 新特性，立即生效）：
1. 电脑上打开 DSH → **设置 → 远程控制 → 公网域名信任白名单**；
2. 添加第 2 步拿到的**公网域名**，格式要求：
   - 纯 `域名` 或 `域名:端口`，**不要带** `http://` / `https://`
   - 例如节点小宝给的是 `http://abc.nodebao.xyz:8123`，就填 `abc.nodebao.xyz:8123`
3. 保存后立即生效（无需重启 DSH）。

### 第 4 步：手机上连接 + 配对
1. 手机打开 **DSH Remote App**，添加主机，地址填第 2 步的**完整公网地址**（含 `http://` 或 `https://`，和端口）；
2. 点连接 → App 弹出「首次配对」；
3. **PC 端会自动生成一个 6 位配对码**（新特性，无需手动点生成）。到电脑 **DSH → 设置 → 远程控制**，能看到当前有效配对码；
4. 把 6 位码填进手机 App → 点「配对」→ 配对完成、自动拿到远程令牌 → 已连接。✅
   - （也可点「等待 PC 确认」走旧式弹窗确认，二选一即可。）
5. 之后 App 会自动记住设备和令牌，重连无需再配对。同样的地址拿到任何网络都能连。

## 四、常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 连接报 **403** | 公网域名没加白名单 | DSH 设置→远程控制→公网域名白名单，加 `域名:端口` |
| 报 **“端口不可达 / PORT_UNREACHABLE”** | 公网地址不对 / 电脑防火墙 / 隧道没起 | 确认 8787 本地能开、节点小宝映射在跑、Windows 防火墙放行 8787 |
| 配对时报 **“已阻止跳过验证”** | 走了旧式确认且插件未确认 | 改用**自动生成的配对码**完成配对 |
| 配对码 **超时/锁定** | 10 分钟过期或输错 5 次 | PC 端会自动再生成一个，重新填 |
| 想踢掉某台手机 | — | DSH 设置→远程控制→已配对设备，删除该设备 |

---

## 五、安全提示
- 只用**你自己**的隧道域名，白名单不要随便加陌生域名；
- 公网地址/域名不要到处乱发，拿到地址的人仍需配对码+令牌才能遥控；
- 不需要远程时，可在 DSH 远程控制里删除已配对设备或直接停掉节点小宝的映射。
